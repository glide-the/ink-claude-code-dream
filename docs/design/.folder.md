# Design

`claude-code-runtime-minimalization.md` is the authoritative 20-section design. Update its evidence date, source/bundle digests, graph counts, DCE/KEEP assertions, MCP/OAuth application state, qualification/package/install receipts, license boundary, business-QA state, and recommendation whenever the build or interface contract changes. Never convert a technical qualification into publication authorization or an unverified real-business pass.

`npm多平台发布设计.md` 定义 `@glide-the` 顶层/平台包、四个 native target、Bun/ripgrep/manifest 校验、零 source map 合同、Windows fail-closed、首次 2FA bootstrap 和后续 OIDC workflow。发布授权必须绑定 checked Dream 回执。

`cleanroom-runtime-architecture.md` 是公共 npm Runtime 的当前目标设计：完全排除恢复源码和旧衍生 bundle，只允许仓库自有 MIT 实现及兼容许可依赖，并以 Dream 的 13 项能力作为发布门。旧 `claude-code-runtime-minimalization.md` 继续保存本地恢复源码裁剪的历史证据，不再作为公共 npm 实现来源。

`cleanroom-runtime-verification.md` 记录 clean-room 的精确版本/协议矩阵、13 项能力到代码与进程测试的映射、四目标/正式五包 digest 与尺寸、CycloneDX/许可证/复现性、macOS arm64 内存、最终 Dream 回执与发布后 registry 验收边界。
