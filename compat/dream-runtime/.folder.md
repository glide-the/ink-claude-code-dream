# Dream Runtime compatibility

`policy.ts` only validates explicit inputs and projects child environments or model
limits. `source-transforms.ts` binds exact original file hashes and markers before
the existing compiler applies in-memory replacements. Neither implements an
Agent, MCP connection, OAuth, credential store or settings state machine.

Original `src` bytes remain unchanged. Notion credentials are stripped from generic
children and final stdio MCP environments. Only Bash can receive a canonical
thread `.notion-home` (0700), a validated native `ntn` and optional safe token and
workers path. Sandbox additions retain existing deny rules and allow only that
home/native executable and the three existing HTTPS domains.

Explicit model carriers are validated without model-ID heuristics. Missing
carriers retain upstream behavior. Capability eligibility requires actual bundle
reachability, policy tests and a digest-bound candidate process receipt; this
folder alone does not claim release qualification.
