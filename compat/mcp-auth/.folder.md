# MCP Auth Compatibility Folder Contract

本目录只承载可独立审查的 MCP 策略辅助函数、纯内存 source transformer 和补丁清单。它不执行网络请求，不实现 OAuth、DCR、PKCE、token store，也不复制 Agent 或 MCP 连接状态机。

## 路由

- `src/headers-helper-policy.ts`：生成 headers helper 子进程的最小环境、作用域 cwd 与 trust 决策。
- `src/redaction.ts`：日志、header 和环境变量脱敏。
- `src/reconnect-policy.ts`：对重连错误分类，并提供有界、可注入的退避重试。
- `src/patch-spec.ts`：stdio ordering、disabled inventory/list/get 和 print/SDK reconcile 的精确源码断言、可执行 transform、postcondition 与稳定虚拟模块解析。
- `src/artifact-receipt.ts`：消费 transformer applied IDs 与实际 bundle/source reachability，只有完整 headless 证据才构造 `applied: true` 回执。
- `src/source-identity.ts`：授权根 realpath/containment/no-symlink/sha256 门禁，以及 artifact receipt 应用状态验证。
- `patch-manifest.json`：只读恢复源码的精确哈希、官方 changelog 证据和未来应用点。
- `tests/`：策略合同、脱敏、清单完整性与只读 restored-source 内存变换/parser 测试。

## 约束

- 不修改或生成 `restored-src` 内容。
- transformer 必须先验证整文件 sha256 与 original-source exact markers，再按清单顺序执行同路径变换，并验证旧 marker 消失和关键顺序 postcondition。
- 不推断 sibling checkout；外部源码证据只允许通过 `INK_AUTHORIZED_CORE_SOURCE_ROOT` 显式指定。
- 不读取、刷新或持久化凭证；调用方只能获得启动策略或重试决策。
- 不从 `process.env` 隐式继承环境；调用方必须显式传入候选环境。
- `patch-manifest.json` 必须保持 `wired: true`、`applied: false`、`status: wired-build-required`；只有覆盖对应 artifact 可达 transform 的 digest-bound 构建产物回执才能派生 `applied: true`。
- headless artifact 只允许回执 `headersHelper.ts`、`client.ts`、`print.ts` 的 reachable transforms；不得把 interactive-only 的 `useManageMCPConnections.ts` 或 `cli/handlers/mcp.tsx` 谎报为已应用。
- 任何未来集成都必须先验证清单绑定的 sha256；目标不匹配时 fail closed。
