# Source modules

- `cli.ts`: executable dispatcher; lazily imports diagnostics or launcher.
- `launcher.ts`: external artifact resolution, doctor-only version gate, explicit bare carriers, TMPDIR, opaque auth/stdio/env spawn, and process supervision.
- `manifest.ts`: lazy immutable release-relative manifest reader, exact-version validator, and digest; not an SDK protocol and not environment-overridable.
- `contracts.ts`: internal manifest and lifecycle types.

Do not add protocol/MCP/settings/transcript parsing, auth selection/filtering, vendor code, or a second state machine to this layer.
