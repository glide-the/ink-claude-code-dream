# Source modules

This is the repository-authored additive implementation layer. The original reconstructed module
layout lives unchanged at `../restored-src/src`; it is not renamed into this directory.

- `cli.ts`: extensionless-console-bin target dispatcher; lazily imports diagnostics or launcher and retains Dream's static `CLAUDE_SECURESTORAGE_CONFIG_DIR` capability marker while leaving secure-storage behavior to the official core.
- `launcher.ts`: external artifact resolution, doctor-only version gate, explicit bare carriers, TMPDIR, opaque auth/stdio/env spawn, and process supervision.
- `manifest.ts`: lazy immutable release-relative manifest reader, exact-version validator, and digest; not an SDK protocol and not environment-overridable.
- `contracts.ts`: internal manifest and lifecycle types, including the current Dream SDK `0.2.145` observation.
- `cleanroom/`: independent MIT headless Runtime and the public native-package build input; restored source is forbidden in its import graph.

Do not add protocol/MCP/settings/transcript parsing, auth selection/filtering, vendor code, or a second state machine to this layer.
