# Source modules

- `cli.ts`: executable dispatcher; lazily imports diagnostics or launcher.
- `launcher.ts`: core resolution, version/doctor, TMPDIR gate, opaque spawn, signal/timeout supervision.
- `manifest.ts`: lazy Runtime-owned manifest reader and digest; not an SDK protocol.
- `contracts.ts`: internal manifest and lifecycle types.

Do not add protocol/MCP/settings/transcript parsing to this layer.
