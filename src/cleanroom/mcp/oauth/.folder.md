# Clean-room MCP OAuth

- `store.ts`: persists one server's OAuth client registration, tokens, PKCE verifier, discovery state, and callback state beneath an explicit canonical `CLAUDE_CONFIG_DIR`.
- `provider.ts`: implements the public `OAuthClientProvider` interface from `@modelcontextprotocol/sdk` 1.30.0, exposes an awaited post-commit token-state callback, and fences late writes after a terminal management cancellation.
- `flow.ts`: exposes headless begin/callback/refresh/logout operations and stable, non-secret error DTOs.
- `probe.ts`: performs unauthenticated challenge and well-known discovery probes without accepting or sending tokens.
- `COMFY.md`: records the token-free Comfy discovery command and explicit external-browser callback boundary.
- `index.ts`: exports the independently testable OAuth surface for later registry integration.

Persistent directories are owned by the current process user and mode `0700`; state files are atomically replaced at mode `0600`. Symlinked or non-canonical configuration paths fail closed. Authorization URLs are returned to the caller, which owns all user interaction.
