# Clean-room MCP management CLI

- `storage.ts`: validates an explicit canonical config root and atomically owns only `.claude.json#mcpServers` and `.credentials.json#mcpOAuth` at modes `0700`/`0600`.
- `argv.ts`: parses the narrow public `mcp list|get|add|remove|login|logout` surface without splitting colon-bearing server names.
- `oauth.ts`: bridges the headless provider to Dream's projected `mcpOAuth` contract, preserves newer private tokens, mirrors token rotation/invalidation atomically, and closes mutation authority before timeout cleanup.
- `index.ts`: renders bounded Dream-parser-compatible status/help output and is the single outer-CLI wire point.

The command never prints config paths, commands, environment values, OAuth tokens, callback URLs, or persisted document contents. Only user-scoped Streamable HTTP mutation is supported. Unsupported scopes and transports fail closed.
