# Extensions

- `skills.ts` discovers project and plugin `SKILL.md` files through real-directory walks, parses only bounded `name`/`description` frontmatter, and returns content only for an explicit allowlist.
- `hooks.ts` validates the SDK initialize hook shape and deterministically selects de-duplicated callback IDs using bounded regular-expression matchers. It has no I/O or mutable global state.
- `index.ts` exposes the extension subsystem without coupling it to provider or protocol state.

Skill definitions never embed Markdown content. The content catalog remains a
separate internal structure so callers can expose only definitions until a
specific allowed Skill is invoked.
