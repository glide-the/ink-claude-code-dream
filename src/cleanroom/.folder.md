# Clean-room Runtime

- `argv.ts`: parses SDK stream-json, session, plugin, and Skill-related command-line options without depending on Claude Code source.
- `headers.ts`: validates `ANTHROPIC_CUSTOM_HEADERS` in Claude Code's newline format (and JSON-object form).
- `protocol.ts`: is the single JSONL state machine; it composes session, MCP, tools, and extensions, including SSE `partial_json`, SDK-visible user/tool-result frames, filtered inventory, callbacks, and OAuth management controls. An explicit PreToolUse `allow` preserves the model `tool_use_id` and skips a second `can_use_tool`; `deny` blocks, while no decision falls through to the permission policy.
- `cli.ts`: exposes the `2.1.241` compatibility surface and owns async startup/shutdown of stdin, sessions, and MCP processes.
- `session/`: writes Dream/SDK-readable `user`/`assistant` transcript envelopes with UUID parent chains while enforcing private storage, fresh/resume/fork identity, and the exact Dream tmpdir boundary.
- `mcp/`: owns provider-free MCP configuration, connection discovery, inventory, resources, headless OAuth, and management controls; it never opens a browser.
- `extensions/`: discovers explicitly selected project/plugin Skills and validates SDK hook metadata; Skill Markdown is loaded into model context only after an explicit `Skill` tool call.
- `settings/`: loads bounded inline/file `--settings` and executes Dream's absolute `apiKeyHelper` without a shell; short-lived subject tokens remain memory-only and are passed only as provider authentication.
- `tools/` and `sandbox/`: implement the bounded Dream file/notebook/todo/task/BashOutput matrix, SDK `can_use_tool` for built-ins and MCP, and file confinement. Production Bash uses Apache-2.0 `@anthropic-ai/sandbox-runtime@0.0.73` (`sandbox-exec`/`bubblewrap`) with default-deny network, private environment, exact Workspace/tmpdir write roots, and no raw-process fallback; the bounded process adapter remains test-only.

This directory is an independent implementation. It must not import, inspect, copy, or embed restored/vendor Claude Code source. Unsupported hook outputs, slash-command Skill execution, and any missing production sandbox adapter remain fail-closed rather than installing fallback behavior.
