# Session persistence

- `paths.ts` validates canonical real directories, derives the private project transcript root, and accepts only the exact `{cwd}/.claude-tmp` directory with mode `0700`.
- `store.ts` owns canonical UUID selection and one `0600` JSONL file per session. Appends are serialized, use one `O_APPEND` write, and are synced before completion; reads consume a fixed-size snapshot.
- `index.ts` is the public module surface for the clean-room runtime.

All persistent paths are derived from an absolute, normalized, non-symlink
`CLAUDE_CONFIG_DIR`. This module must never inspect or import restored source.
