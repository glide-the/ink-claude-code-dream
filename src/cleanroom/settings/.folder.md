# Settings and provider authentication

- `settings.ts` accepts one bounded inline JSON object or a regular settings file. File paths are resolved from the Runtime `cwd`; symbolic links, non-owner-writable trust failures, oversized files, and non-object JSON fail closed.
- `helper.ts` parses the narrow POSIX command form emitted by Dream, resolves an absolute executable without a shell, rejects writable/unexecutable targets, applies a bounded timeout, and accepts exactly one bounded token line.
- `provider-auth.ts` applies the documented direct credential precedence, otherwise keeps `apiKeyHelper` results only in process memory for the bounded `CLAUDE_CODE_API_KEY_HELPER_TTL_MS` interval. Tokens never enter JSONL, stderr, manifests, transcripts, or the filesystem.

This module is a provider-auth adapter only. It does not import Dream DTOs, issue Gateway subjects, or copy the Admin Gateway state machine.
