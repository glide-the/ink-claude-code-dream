# Clean-room tools

- `definitions.ts`: public Anthropic Messages-compatible schemas for `Read`, `Write`, `Edit`, `Glob`, `Grep`, and `Bash`.
- `workspace.ts`: canonicalizes the configured `cwd`, rejects lexical escape and symlink escape, and resolves safe read/write targets.
- `permissions.ts`: applies `allowedTools`, `disallowedTools`, and permission-mode policy, then bridges unresolved decisions through the SDK `can_use_tool` control channel.
- `dispatch.ts`: validates input and executes the bounded built-in inventory. File mutations are atomic and never follow a final symlink; an explicit protocol-level hook grant bypasses only the duplicate permission callback, never input or Workspace checks.

The Workspace boundary is mandatory. Unknown tools, malformed inputs, permission failures, and paths outside the canonical root fail closed. `Bash` additionally requires an injected trusted sandbox backend; the default sandbox never starts a process.
