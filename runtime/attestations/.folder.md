# Runtime attestations

`dream-real-business-acceptance-0.1.0.json` records the privacy-redacted result of the final Dream business journey. It binds the accepted local fixture tarballs and native executable, documents the public production entrypoints exercised, and records the explicit release authorization.

`dream-real-business-acceptance-0.1.1.json` binds the MCP authentication-routing release to the reviewed Runtime PR/CI evidence, the authenticated and anonymous Server journeys, automatic OAuth callback, tools/resources/prompts inventory, partial-failure isolation, cancel, and same-thread resume. Its artifact digests are fixed before the publication workflow runs.

Packaging and workflows verify the checked file's SHA-256 through `runtime/cleanroom-artifact-policy.json`. Generated npm packages carry only that digest in `npm-publication-attestation.json`; they do not bundle this receipt or any real account, database row, request body, OAuth credential, callback, transcript, or raw log.
