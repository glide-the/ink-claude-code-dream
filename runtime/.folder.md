# Runtime manifests

- `release-manifest.json`: Runtime-owned `ink-claude-cli-envelope/v1` diagnostic contract.
- `capabilities.json`: detailed delegated/enforced capability and evidence matrix.
- `platforms.json`: external official `2.1.241` Linux package pins.
- `artifact-manifest.json`: user-supplied, external, unmodified official artifact and redistribution gate.
- `entrypoint-policy.json`: wrapper/child boundary, management commands, authentication preservation, and no-injection policy.
- `runtime-data-contract.json`: workspace/TMPDIR/transcript/MCP/plugin/auth ownership and lifecycle.
- `bare-profile.json`: explicit caller-supplied `--bare` carrier requirements and production blocker.
- `dependency-licenses.json`: build dependency licenses plus official legal/publish decision.

All contracts are copied into the release and verified by `scripts/verify-release.mjs`; none is negotiated by the unchanged Python SDK. Never place a core binary, vendor/restored source, user material, or secret here.
