# Runtime manifests

- `release-manifest.json`: Runtime-owned `ink-claude-cli-envelope/v1` diagnostic contract.
- `capabilities.json`: detailed delegated/enforced capability and evidence matrix for Dream's locked CLI `2.1.241` and `ink-claude-dream-agent-sdk==0.2.143`.
- `platforms.json`: external official `2.1.241` Linux package pins.
- `artifact-manifest.json`: user-supplied, external, unmodified official artifact and redistribution gate.
- `entrypoint-policy.json`: wrapper/child boundary, management commands, authentication preservation, and no-injection policy.
- `runtime-data-contract.json`: workspace/TMPDIR/transcript/MCP/plugin/auth ownership and lifecycle.
- `bare-profile.json`: explicit caller-supplied `--bare` carrier requirements and production blocker.
- `dependency-licenses.json`: build dependency licenses plus official legal/publish decision.
- `cleanroom-artifact-policy.json`: restored-source-free MIT Runtime boundary, Dream's 13 required capabilities, prohibited inputs, target qualification basis, and digest-bound Dream real-business/publication evidence gate.
- `attestations/`: public, privacy-redacted release receipts. Raw accounts, logs, database rows, OAuth material, callbacks, and transcripts are forbidden.
- `cleanroom-npm-policy.json`: exact Bun cross-compile target, five scoped package identities, Dream-compatible `bin/ink-claude-code-dream` plus release/capability manifests, native magic, checksum, CycloneDX SBOM, license, mutable-data, and zero-source-map requirements for the clean-room release set.
- `cleanroom-sandbox-policy.json`: exact Apache-2.0 Sandbox Runtime pin, four supported targets, Workspace/tmpdir/network/environment/process bounds, and the no-raw-process fallback rule.
- `cleanroom-dependency-licenses.json`: exact dependency/license/file inventory for every third-party package reachable from the clean-room CLI bundle; packaging turns it into a checked report and third-party notices.
- `pruning-decision.json`: executable fail-closed core-pruning decision, candidate evidence, and authorization/build inputs required before any vendor-core deletion.
- `core-prune-profile.json`: Bun `1.4.0` local build profile, retained Dream capabilities (including synchronous Agent/Task, MCP management, sandbox, and image roots), authorized package-asset manifest, disabled feature set, defines, and suffix/prefix/output DCE assertions.
- `core-resolution-map.json`: deterministic exact/prefix bare-specifier and digest-bound facade mapping for explicitly supplied external source/package trees, including the narrow MCP management entry and importer-aware `signal-exit` API split; unresolved entries fail and remain local evidence.
- `local-artifact-policy.json` / `local-release-manifest.json`: production-qualified local package identity plus the separately installed `ink-claude-code-bun-1.4.0` toolchain contract; the Runtime artifact does not bundle or overwrite ambient Bun.
- `npm-release-policy.json`: `@glide-the` selector/platform package names, four native targets, exact `bun@1.4.0`, ripgrep checksums, source-map/user-data exclusions, Windows/musl refusal, and Trusted Publishing identity. It references but never overrides the closed local legal policy.

The legacy envelope contracts are copied into the release and verified by `scripts/verify-release.mjs`; none is negotiated by the unchanged Python SDK. The clean-room `0.1.0` publication gate is open only because the checked acceptance receipt digest, independent build, target artifact qualification, and explicit authorization all passed. Never place a core binary, vendor/restored source, user material, or secret here.
