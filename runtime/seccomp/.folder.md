# Seccomp deployment assets

- `apply-seccomp-passthrough-v2.1.88.sh` is the Linux local-core `vendor/seccomp/<arch>/apply-seccomp` implementation for the restored 2.1.88 sandbox-runtime interface.
- The 2.1.88 helper receives `unix-block.bpf` as argv 1, so the shim removes exactly that argument and executes the remaining command.
- `build-core-prune.ts` copies it directly into the checksum-verified local-core artifact; deployment does not mutate the packaged helper afterward.

The passthrough disables only the Unix-socket seccomp filter. It does not make bubblewrap work on a host that forbids user or mount namespace creation, and it must not be copied into the public clean-room npm packages.
