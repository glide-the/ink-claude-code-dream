# Claude Plugin Marketplace metadata

`marketplace.json` is the repository-owned Claude Code catalog. Entries may point to
reviewed external plugins, but must use immutable source revisions and describe the
installed capability precisely. A catalog entry is distribution metadata only: it must
not claim that this headless Runtime can render MCP Apps or that an installed Skill is an
MCP server.
