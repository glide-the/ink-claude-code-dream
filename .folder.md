# Repository map

- `src/`: transparent CLI, launcher, manifest diagnostics, and types.
- `package/`: canonical clean-room selector source in the reference package-root shape: private `package.json`, `cli.js`, package README, and license; generated manifests/native binaries remain outside it.
- `.claude-plugin/`: Claude Code Marketplace catalog for reviewed, immutable external development plugins; catalog inclusion never implies Runtime protocol support.
- `runtime/`: checked-in capability profiles, clean-room npm policies, privacy-redacted acceptance attestations, native matrices, external artifact/data contracts, platform pins, and fail-closed legacy pruning decisions.
- `compat/`: clean-room, independently testable compatibility policies; MCP `2.1.238`/`2.1.239` work remains separate from restored `2.1.88` and is source-bound into the qualified core.
- `scripts/`: Bun/Node/Python build, verify, package, benchmark, compatibility, and local core-prune runners.
- `tests/`: provider-free process-boundary and core-prune contract tests.
- `docs/`: authoritative design, build, and acceptance guidance.
- `dist/core-local/`: generated Bun core evidence/output; always Git-ignored and local-only, and used only to produce the qualified local package.
- `dist/core-package-local/`: reproducible qualified local package; always Git-ignored, publication/redistribution disabled.
- `dist/cleanroom-targets/` and `dist/cleanroom-npm/`: generated formal clean-room executables, staging directories, and tarballs; always Git-ignored and bound to checked policies/attestations.
- `dist/npm-stage/` and `dist/npm-tarballs/`: generated legacy scoped npm staging/tarballs; always Git-ignored and unreachable while legacy legal flags remain closed.
- `dist/release/`: reproducibly generated immutable reviewed release; archives remain local outputs.
- `bun.lock` and root `package.json`: private Bun build/test orchestration contract named `ink-claude-code-dream`; it has no CLI bin or publish identity. The local core builder requires pinned Bun `1.4.0`.
- `LICENSE`: MIT license for repository-authored source, build tooling, tests, manifests, and documentation only; it does not relicense external or recovered Anthropic code.

The authorized restored source remains external and read-only to this repository. No restored/vendor source, generated derived core, vendor binary/map, Dream business code, user material, settings, credentials, or secrets belong in Git or a public release. Repository-authored code is MIT-licensed. A Runtime artifact may use that license only after its build proves that every executable input comes from this repository or a compatible third-party dependency and that no restored-source-derived byte entered the artifact.
