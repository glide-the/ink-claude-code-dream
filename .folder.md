# Repository map

- `src/`: transparent CLI, launcher, manifest diagnostics, and types.
- `runtime/`: checked-in Runtime evidence, external artifact/entrypoint/data/bare/license contracts, and platform pins.
- `scripts/`: Bun/Node/Python build, verify, package, benchmark, and compatibility runners.
- `tests/`: provider-free process-boundary fixtures and tests.
- `docs/`: authoritative design, build, and acceptance guidance.
- `dist/release/`: reproducibly generated immutable reviewed release; archives remain local outputs.
- `bun.lock` and `package.json`: Bun dependency/script contract; production target is Node.

No Claude core/binary/map, restored/vendor source, Dream business code, user material, settings, credentials, or secrets belong in this repository. The external binary must remain unmodified, run as published, preserve built-in authentication, and remain outside the release and git.
