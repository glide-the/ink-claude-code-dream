# Tests

`runtime.test.mjs` covers opaque bytes/argv/env, MCP/auth/version/help forwarding, authentication-environment presence without value logging, the built macOS secure-storage capability marker, external path/doctor/TMPDIR gates, explicit bare profile/no injection, skip rejection, exit/signal/timeout cleanup, and esbuild lazy imports. `differential.test.mjs` sends identical provider-free JSONL and management requests directly to the deterministic fake core and through the envelope, then compares argv, stdin/stdout/stderr, cwd, selected environment, exit status, and the intentional SIGTERM/descendant-cleanup difference. Lifecycle fixtures emit readiness only after their signal handler and PID receipts exist; tests clean wrapper, core process group, and descendant in `finally`, including failed assertions. Tests do not make provider/model/OAuth/Remote calls and cannot claim official-core behavior or Dream business E2E.

`core-prune-contract.test.mjs` statically verifies the Bun `1.4.0` pin, explicit authorized source/package-root boundaries, ignored local-only output, digest-bound assets, required capability roots, narrow MCP entry, deterministic resolver/facade controls, DCE assertions, and the source-bound provider-instance client memo. It never reads or builds restored source.

`core-mcp-management-contract.test.mjs` calibrates the official CLI and exercises the candidate through Dream's real management adapter using provider-free local fixtures; `core-package-local.test.mjs` proves receipt binding, closed publication gates, Dream manifest compatibility, source/user-data exclusion, tamper detection, byte-identical packaging, content-addressed installation, isolated Bun `1.4.0` discovery, and refusal to overwrite non-symlink user files.

`core-mcp-oauth-cli.test.mjs` runs pipe and Dream-compatible real-PTY lanes with separate disposable `CLAUDE_CONFIG_DIR` and `CLAUDE_SECURESTORAGE_CONFIG_DIR`. It rejects relative and non-normalized selectors and installs a fake `security` sentinel that fails the test if an actor-selector flow touches the macOS keychain. The contract proves `.credentials.json` exists only under the valid secure selector with mode `0600`, the ordinary config contains no credential file, post-save reports `credentials_present`, and a fresh process reports Connected. It also validates the exact 16-stage success path, missing post-save credentials as a fixed failure rather than false success, fixed failure categories, sensitive-data exclusion, and race-safe observation of a child that exited before listener registration.

`npm-release-contract.test.mjs` verifies the exact `@glide-the` four-platform selector matrix, native ripgrep identities, Windows refusal, checked legal failure, root legacy-envelope pack refusal, Trusted Publishing runner/OIDC contract, scoped Environment-token fallback with OIDC removal and explicit publish-time provenance suppression, and actual clean/bad npm tgz behavior. A tarball containing any `*.map` must fail even when npm itself includes it.

`cleanroom-*.test.mjs` is the provider-free qualification set for the repository-authored Runtime: SDK JSONL/SSE and user/tool-result parsing, Dream-readable private transcript/resume/tmpdir, filtered Skills/tools inventory, Workspace and permission boundaries, the local notebook/todo/task/BashOutput matrix, bounded signals, stdio/legacy-SSE/Streamable-HTTP MCP plus anonymous-first/headless OAuth routing, Dream's inline/file `apiKeyHelper` bootstrap, real host OS sandbox isolation plus compiled-standalone sandboxed Bash, the integrated process loop, and the four-platform/five-package npm artifacts with installed CycloneDX/license evidence. MCP tests keep legacy SSE distinct from Streamable HTTP, prove initialize/discovery/call/read/reconnect/close, keep `list` one-line-per-server, place authentication details on `get`, preserve marker-free HTTP and SSE projected refresh across restart, reject naked or non-Bearer 401 as unadvertised, validate protected-resource/issuer/endpoint metadata, safely classify later SSE POST 401/403, union prior and challenged scopes through the SDK's bounded step-up, exhaust tools/resources/prompts pagination, and distinguish callback cancellation from EOF without exposing secrets. The npm test verifies the checked Dream receipt digest, formal no-fixture attestations, successful generated prepack, local install/select, aliases, signal handling, and—when a sibling Dream checkout/Python exists—the real Python resolver. Provider-free tests do not recreate the externally completed real Gateway/Dream acceptance; they verify its checked binding.
