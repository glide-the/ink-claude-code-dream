# Package source template

- `package.json`: canonical public selector identity, version, two bin aliases, Node range, and exact optional native packages. It intentionally has no `exports` field, matching the reference CLI-only package contract.
- `cli.js`: the single package-root selector and process supervisor used by both command aliases.
- `README.md`: package-specific installation/runtime boundary.
- `LICENSE.md`: license for this repository-authored selector template, kept at package root like the reference artifact.

The template stays `private: true` so direct publication fails. `scripts/npm-release.mjs` copies these reviewed inputs into a generated stage, adds manifests/attestations/license material, removes only the private guard there, and never publishes by itself.
