# Automation

- `build.ts`, `verify-release.mjs`, `pack-release.mjs`, `check-reproducible.mjs`: deterministic release pipeline with Bun `1.2.20`, fixed epoch, and exact Node `24.13.0` archive-packer receipt/gate.
- `lint.mjs`: read-only clean-room, legal-contract, version, header, secret, and vendor-material gate.
- `run-acceptance.mjs`, `benchmark-official.mjs`: credential-free metrics/difference evidence.
- `run-upstream-sdk-contract.mjs`, `verify-upstream-sdk-contract.py`: read-only Dream cli_path acceptance that sends the same provider-free SDK JSONL request directly to the fake core and through the envelope. Default verification requires only `ink-claude-dream-agent-sdk==0.2.143` and fails if the official `claude-agent-sdk` distribution coexists.
- `run-mcp-matrix.mjs`, `verify-mcp-version.py`: disposable public-package MCP regression.
- `verify-pruning-evidence.mjs`: optional read-only historical-source inventory/path verifier; requires explicit `INK_RESTORED_SOURCE_ROOT` and never copies source.
- `build-core-prune.ts`, `verify-core-prune.mjs`: isolated Bun `1.4.0` source/package-root build and local receipt gate. They require explicit authorized absolute roots, preserve SDK stream-json plus a narrow MCP management entry, copy only digest-bound runtime assets (currently ripgrep plus its license), enforce prefix/output DCE and path-identity scrubbing, and may write only ignored `dist/core-local/`.
- `run-core-mcp-management-contract.py`: invokes Dream's production MCP CLI driver/parser against an exact candidate identity in disposable `HOME`/config/secure-storage directories, covering user HTTP lifecycle, colon names, bounded redaction, and OAuth command availability without claiming a complete OAuth exchange.
- `qualify-core-local.mjs`, `package-core-local.mjs`, `verify-core-package-local.mjs`: bind SDK, MCP session, and MCP management process receipts to exact core/source digests; package a reproducible local-only Bun artifact; and fail closed on production eligibility, material boundaries, checksums, or legal-policy drift. Stale implicit receipts are treated as absent, while an explicitly supplied stale receipt is rejected.

Scripts may write repository `dist/` or disposable temp directories only. They must not install into or modify Dream, SDK, restored-source, or user environments.
