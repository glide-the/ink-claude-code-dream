# Automation

- `build.ts`, `verify-release.mjs`, `pack-release.mjs`, `check-reproducible.mjs`: deterministic release pipeline with Bun `1.2.20`, fixed epoch, exact Node `24.13.0` archive-packer receipt/gate, and a hard ban on `*.map` output.
- `lint.mjs`: read-only clean-room, legal-contract, version, header, secret, and vendor-material gate.
- `run-acceptance.mjs`, `benchmark-official.mjs`: credential-free metrics/difference evidence.
- `run-upstream-sdk-contract.mjs`, `verify-upstream-sdk-contract.py`: read-only Dream cli_path acceptance that sends the same provider-free SDK JSONL request directly to the fake core and through the envelope. Default verification requires only `ink-claude-dream-agent-sdk==0.2.143` and fails if the official `claude-agent-sdk` distribution coexists.
- `run-mcp-matrix.mjs`, `verify-mcp-version.py`: disposable public-package MCP regression.
- `run-core-oauth-cli-contract.mjs`: fail-closed executable headless OAuth gate. It requires explicit official MCP Python SDK `v2.0.0` fixture/Python paths, rejects modified provider source, and delegates the full DCR/PKCE/callback/token/persistence flow to the official SDK fixture.
- `run-core-sdk-contract.py`, `run-core-sdk-differential.mjs`: compare the official `2.1.241` process and the restored candidate through the real SDK/Bash boundary. In nested Docker only, the runner injects `allowAllUnixSockets` into the official reference lane because its embedded helper is not replaceable; it explicitly removes that harness flag from the candidate lane, which must execute the restored disk helper. The receipt records the asymmetry and both lanes must retain bwrap filesystem/credential isolation.
- `verify-pruning-evidence.mjs`: optional read-only historical-source inventory/path verifier; requires explicit `INK_RESTORED_SOURCE_ROOT` and never copies source.
- `build-core-prune.ts`, `verify-core-prune.mjs`: isolated Bun `1.4.0` source/package-root build and local receipt gate. They require explicit authorized absolute roots, preserve SDK stream-json plus a narrow MCP management entry, and apply digest-bound transforms. Linux targets additionally restore the 2.1.88 sandbox-runtime disk contract at `chunks/vendor/seccomp/<arch>/{apply-seccomp,unix-block.bpf}`: `apply-seccomp` is the repository-authored Docker-style passthrough and the BPF is the exact Apache-2.0 `@anthropic-ai/sandbox-runtime@0.0.45` asset. Receipts bind source identity, digest, mode, and output path. A valid absolute, normalized, NFC `CLAUDE_SECURESTORAGE_CONFIG_DIR` is authoritative and selects only its actor-owned `0600` credential file; it never invokes the user's keychain. An invalid selector fails closed, while an unset selector preserves the official macOS keychain-with-plaintext-fallback behavior. Token persistence checks `storage.update`, and a missing post-save credential read is also a fixed classified failure; neither path may emit success. Provider memoization remains limited to DCR client information—never tokens, codes, or verifiers—and the successful receipt remains exactly 16 lines.
- `run-core-mcp-management-contract.py`: invokes Dream's production MCP CLI driver/parser against an exact candidate identity in disposable `HOME`/config/secure-storage directories, covering user HTTP lifecycle, colon names, bounded redaction, and OAuth command availability without claiming a complete OAuth exchange.
- `qualify-core-local.mjs`, `package-core-local.mjs`, `verify-core-package-local.mjs`: bind SDK, MCP session, and MCP management process receipts to exact core/source digests; package a reproducible local-only Bun artifact; and fail closed on production eligibility, material boundaries, checksums, or legal-policy drift. Stale implicit receipts are treated as absent, while an explicitly supplied stale receipt is rejected. The launcher discovers the separately installed versioned `ink-claude-code-bun-1.4.0` before ambient `bun`.
- `install-core-local.mjs`: verifies a production-qualified package and exact Bun `1.4.0`, copies both into content-addressed user-prefix directories, then atomically installs only the two PATH symlinks. It refuses non-symlink replacements and never changes the user's global `bun`.
- `npm-root-guard.mjs`: rejects root `npm pack/publish` so the legacy envelope can never masquerade as the minimal Runtime.
- `npm-release.mjs`: prints the four-platform `@glide-the` layout; after all checked/package legal and qualification gates pass, atomically stages one native platform package plus the selector package. It validates target-specific ripgrep and refuses every `*.map`.
- `verify-npm-tarball.mjs`, `smoke-npm-release.mjs`: inspect the final tgz, run npm dry-run/pack, clean-install both packages, verify exact Bun `1.4.0`, and execute CLI `--version`. Current closed legal flags intentionally prevent staging.
- `build-cleanroom-runtime.ts`: compile the host clean-room CLI for focused protocol tests with source maps disabled.
- `build-cleanroom-targets.ts`: cross-compile the repository-authored clean-room entrypoint into the exact Darwin/Linux arm64/x64 standalone matrix and emit digest-bound manifests.
- `package-cleanroom-npm.mjs`, `verify-cleanroom-npm.mjs`: stage, pack, and verify the MIT selector plus four platform packages, exact optional dependencies, Dream's canonical executable/release manifest/capability evidence, native identity, checksum/CycloneDX/license bindings, restricted-material exclusions, and a hard zero-`.map` rule. The packager maps `runtime/cleanroom-artifact-policy.json#requiredCapabilities` into all five generated manifests. Formal packages require a version-bound privacy-redacted Dream acceptance digest, all target qualifications, and explicit npm authorization; only the same main SHA that passes qualification may reach the publisher.

Scripts may write repository `dist/` or disposable temp directories only. They must not install into or modify Dream, SDK, restored-source, or user environments.
