# Automation

- `build.ts`, `verify-release.mjs`, `pack-release.mjs`, `check-reproducible.mjs`: deterministic release pipeline with Bun `1.2.20`, fixed epoch, and exact Node `24.13.0` archive-packer receipt/gate.
- `lint.mjs`: read-only clean-room, legal-contract, version, header, secret, and vendor-material gate.
- `run-acceptance.mjs`, `benchmark-official.mjs`: credential-free metrics/difference evidence.
- `run-upstream-sdk-contract.mjs`, `verify-upstream-sdk-contract.py`: read-only existing SDK/Dream cli_path acceptance.
- `run-mcp-matrix.mjs`, `verify-mcp-version.py`: disposable public-package MCP regression.
- `verify-pruning-evidence.mjs`: optional read-only historical-source inventory/path verifier; requires explicit `INK_RESTORED_SOURCE_ROOT` and never copies source.

Scripts may write repository `dist/` or disposable temp directories only. They must not install into or modify Dream, SDK, restored-source, or user environments.
